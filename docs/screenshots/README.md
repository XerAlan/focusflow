## 推荐分辨率

- **截图**：`1440 × 900`（16:10）或 `1920 × 1080`（16:9）
- **GIF**：建议 `1280 × 720` 或更小，便于在 README 中流畅播放

## Windows 采集工具

### 静态截图
- **Win + Shift + S**：系统自带截图工具（推荐）
- **Snipping Tool / 截图工具**（Windows 11 自带）
- **ShareX**（免费开源，功能强大）：https://getsharex.com

### 录屏转 GIF
- **ScreenToGif**（免费开源，最易用）：https://www.screentogif.com
  - 步骤：录制器 → 选择窗口 → 开始录制 → 演示功能 → 停止 → 保存为 GIF
  - 编辑器可裁剪、调整帧率
- **ShareX**：也可录屏并直接转 GIF
- **ffmpeg**（命令行）：更精细控制
  ```bash
  ffmpeg -i input.mp4 -vf "fps=15,scale=1280:-1" -loop 0 output.gif
  ```

## 采集建议

1. **窗口大小**：先调整到目标分辨率（如 1440×900），再截图
2. **数据准备**：预先填入一些 Todo / 预设软件 / 留言，让界面更饱满
3. **暗色主题**：项目默认就是暗色，确保系统主题不是浅色
4. **干净状态**：截图前关闭所有 toast、模态框
5. **GIF 演示动作建议**（demo.gif）：
   - 0-2s: 启动展示主界面
   - 2-4s: 拖拽 Todo 排序
   - 4-6s: 点击番茄钟「开始」
   - 6-8s: 点工作模式按钮 → 显示启动状态
   - 8-10s: 切到留言面板 → 输入文字 → 自动保存提示

## 压缩优化

如果 GIF 过大：
- 用 ScreenToGif 编辑器降低帧率（10-15 fps 通常足够）
- 缩小尺寸（1280×720 已经很清晰）
- 用 https://ezgif.com/optimize 进一步压缩
