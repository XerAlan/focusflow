# Renderer Components

此目录包含所有 React UI 组件。

- `PomodoroTimer.tsx`：番茄时钟（圆形进度 + 控制）
- `TodoList.tsx`：待办列表（增删改查 + 拖拽排序 + 分组）
- `PresetAppsGrid.tsx`：预设软件快捷网格
- `StatsChart.tsx`：近 7 天专注时长柱状图
- `AudioPlayer.tsx`：本地音乐播放器（Howler.js）
- `SettingsModal.tsx`：设置模态框（含工作模式配置子组件）
- `WorkModeButton.tsx`：一键工作模式按钮
- `ErrorBoundary.tsx`：React 错误边界
